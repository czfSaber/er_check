# 应急响应人工排查手册（v1.0）

配套 [`er_check.py`](../er_check.py) 的**离线纸质版**。把脚本覆盖的 65 个检查项（Windows 33 + Linux 32）展开成现场可手工执行的清单，供「不能联网、不能插 U 盘、不能装工具」的主机使用：照着命令逐条敲，把输出填进章末汇总表，最后按第 7 章收敛结论。

## 每个检查项的写法

固定五段，缺一不可：① 检查目的 ② 执行命令（标 `cmd` / `powershell` / `bash`）③ 正常样例 ④ 异常特征 + 级别 ⑤ 证据留存；需要管理员/root 的命令单独标注，容易被误报的项附「如何排除误报」。

④ 表格的**来源**列区分判据出处：

- **脚本** —— 该判据在 `er_check.py` 有等价实现，附函数名与关键行号（如 `win_autoruns()` `L1490`）。行号是 **er_check 1.0 的代码快照**，脚本重构后请以函数名为准
- **经验** —— 脚本没有该判据，属现场经验补充

## 重出手册

```bash
cd build
python build.py                      # 生成 HTML + pagemap.json，并打印总页数
chrome --headless=new --no-pdf-header-footer --virtual-time-budget=25000 \
       --print-to-pdf=../_raw.pdf "../应急响应人工排查手册_v1.0.html"
python add_bookmarks.py              # 写入 PDF 书签（Chrome 不自带大纲）
python check_overflow.py             # 逐页校验，必须 overflow pages: 0
```

依赖：Chrome（测量与打印）、`pypdf`（加书签）。改内容只动 `data_win.py` / `data_linux.py` / `data_ch0_4.py` / `data_ch5_7.py` / `sources.py`，`build.py` 与 `style.css` 是排版层。

⚠️ 任何内容长度变化都会让装箱结果变化，**页码、目录、书签会一起重排**，属预期行为；改完务必跑一遍 `check_overflow.py`。

## 只读声明

手册内全部命令均为只读：不删除、不修改、不结束进程、不重启。唯一的写操作集中在第 7.5 节『【处置】（取证之后再操作）』，且必须在证据固定、哈希记录、报告初稿之后执行。手册不含二维码、网址与外部字体，可在完全离线的打印环境使用。
